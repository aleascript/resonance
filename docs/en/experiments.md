# Experiments

Resonance is tested by making things with it. The current projects already follow more than one branch.

## Regard

[**Regard**](https://aleascript.github.io/regard) is a TTRPG framework developed through Resonance, with a fully playable standard configuration.

Regard can in turn be used to build games. Current implementations include [Glorantha Perspectives](https://aleascript.github.io/glorantha-perspectives) and [Scooby-Doo](https://aleascript.github.io/scooby-doo).

Regard is an important result of Resonance, but it is not the definition of Resonance.

## Unmind

[**Unmind**](https://aleascript.github.io/unmind) is a standalone experimental TTRPG developed directly through Resonance.

It does **not** use Regard. Its existence is deliberate evidence that Resonance can lead to different game architectures when the intended experience demands them.

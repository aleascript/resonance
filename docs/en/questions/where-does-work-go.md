# Where does the work go when we simplify?

A rule disappears. Has the game become simpler?

Not necessarily.

Its work may have moved to the GM, player improvisation, group negotiation, preparation, memory, or implicit genre knowledge.

The useful question is:

> **When something becomes easier here, who or what is now doing the work?**

A first attempt to map this appears in [Accessibility and load distribution](../accessibility.md).
